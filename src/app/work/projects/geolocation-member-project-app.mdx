## Overview

In this project, we focused on the features that the client needed and created a member map with geo location, project creation and management with image and pdf uploads, links, and user permissions

## Key Features

- **Google API Geolocation Integration** Built out a UI that displays users based on permissions
- **Code Generation**: Utilized the vibing coding app Lovable to craft an app that focuses on the key features tailor to the client
- **Continuous Sync**: The codebase is synced with GitHub allowing for me to edit on my local and push to the remote which deploys to the Lovable server.
- **Managed Service & Database**: It provides a backend-as-a-service (BaaS) with a managed PostgreSQL instance, simplifying database management and reducing the complexity of setting up a backend infrastructure. Supabase focuses on providing a seamless and intuitive developer experience.

## Technologies Used

- **Google API**: For extracting design tokens and component data directly from the Figma designs.
- **React and Vite**: For building the front-end codebase with clean, reusable components.
- **Styled-Components**: For managing styles dynamically using design tokens.
- **GitHub**: For automating the pipeline and syncing design changes to the repository.
- **Lovable**: is an AI-powered, full-stack development platform that allows users to create and launch web applications simply by describing their idea in plain English. It is often described as a "vibe coding" tool, where users chat with the AI to turn concepts into functional websites and apps without needing to write code.
- **Supabase**: Its integrations with platforms like Vercel and Lovable and its overall ease of use make it a good fit for teams working with modern web development stacks.

## Challenges and Learnings

One of the biggest challenges was ensuring that the generated code was clean and maintainable. This involved reviewing components and React code structures, as well as managing edge cases like responsive design and conditional rendering. Additionally, the continuous synchronization required a robust error-handling system to prevent conflicts during development.

## Outcome

The automated Lovable to code pipeline has streamlined the handoff process, cutting down design-to-development time by 60%. This project has proven the value of automation in bridging the gap between designer and developer.
